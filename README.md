# ⚡ MC Skripts

Vítej v mém repozitáři se skripty pro Minecraft (plugin **Skript**). Najdeš tu vlastní implementace, pokusy i pomocné nástroje.

---

## 📂 Struktura a popis složek/souborů

### 📁 `essentials.sk` / Složka `essentials`
* Vlastní skript napsaný jako náhrada za klasický plugin Essentials. Obsahuje základní příkazy a funkce pro fungování serveru.

### 📁 `gens` (Nedokončeno)
* **Stav:** Rozdělané a opuštěné (k tomuto projektu se už pravděpodobně nevrátím).
* **Popis:** Pokus o vytvoření vlastní minihry / generátorů na serveru.

### 📁 `globals`
* Globální proměnné, funkce nebo nastavení sdílená napříč ostatními skripty.

---

## 📜 Seznam samostatných skriptů

| Název souboru | Popis |
| :--- | :--- |
| `api.sk` | Pomocné API pro propojení a komunikaci mezi skripty. |
| `crates.sk` | Systém beden (crates) a otevírání odměn. |
| `custom_enchant.sk` | Vlastní očarování (enchantmenty) pro předměty. |
| `customcommand.sk` | Správa vlastních příkazů na serveru. |
| `duel_sands.sk` | Aréna / soubojový systém (duely). |
| `hopsukprasek.sk` | Zábavný / testovací skript (skákací prášek). |
| `lobbycommand.sk` | Příkazy a funkce specifické pro lobby serveru. |
| `rotationblock.sk` | Mechanika rotujících bloků. |
| `store.sk` & `storeText.sk` | Skripty pro herní obchod / store. |
| `testgui.sk` | Testovací rozhraní (GUI) pro různé interaktivní prvky. |
| `test.sk` / `test_blbosti.sk` | Testovací skripty, experimenty a různé "blbosti". |

---
*Poznámka: Některé soubory s pomlčkou na začátku (např. `-secretlol.sk`) jsou archivované nebo vypnuté.*
